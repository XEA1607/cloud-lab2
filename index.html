本页面是《云计算与分布式系统》课程实验2的成果。实验使用 GitHub 的 Pages 服务作为云环境， 把网页文件提交到远程仓库后，由 GitHub 的服务器对外提供 HTTP 访问， 不需要自己维护服务器和公网 IP。页面能通过下面的网址访问到，即说明实验完成。

实验内容

  • 在 GitHub 上创建代码仓库，并把本地的网页文件推送到远程仓库。
  • 在仓库的 Settings → Pages 中启用 Pages 服务，选择 main 分支根目录作为发布源。
  • 等待构建完成后，用浏览器访问 GitHub 给出的网址，确认页面可以正常打开。

实验体会

实验中最直观的感受是云服务把服务器、域名和部署工具都打包成了现成的服务： 只需要提交几个静态文件，剩下的构建、托管和访问都由平台完成， 自己不用安装 Web 服务器，也不用考虑公网 IP 和带宽。 这说明云平台的价值不只是“把机器放到网上”，更重要的是把运维工作也一起托管了。
